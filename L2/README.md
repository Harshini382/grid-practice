
# Level 2 - Intermediate CSS Grid Practice

## Description

This project contains my Level 2 CSS Grid and responsive web design practice questions.

I created these examples to improve my understanding of CSS Grid, responsive layouts, CSS units, and Git.

## Features

- Two-column sidebar and main layout
- CSS Grid card spanning
- Responsive gallery using media queries
- Auto-fit and minmax
- Hero section using vh and vw
- Button styling using em and rem
- Git feature branch and navbar
