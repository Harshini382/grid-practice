
# ShopEase – Responsive E-commerce Product Page

A responsive e-commerce product listing page built using HTML5 and CSS3.

## Features

- Responsive product grid using CSS Grid auto-fit
- Product cards with images and prices
- Filters sidebar
- Filters move below products on mobile
- Sticky footer using Flexbox
- Responsive desktop, tablet and mobile layouts

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## How to Run

1. Clone the repository.
2. Open the `Q3-ecommerce-product-page` folder.
3. Open `index.html` in your browser.

No additional dependencies are required.
