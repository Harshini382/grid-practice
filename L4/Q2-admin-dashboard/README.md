
# AdminPro – Responsive Admin Dashboard

A responsive admin dashboard built using HTML5 and CSS3.

## Features

- Top navigation bar
- Sidebar navigation
- Four statistics cards
- Revenue overview chart
- Customer growth chart
- Recent orders table
- Responsive single-column mobile layout

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## How to Run

1. Clone the repository.
2. Open the `Q2-admin-dashboard` folder.
3. Open `index.html` in your browser.

No additional dependencies are required.
